### 1. Problem Definition & Scope
StudentHub is a unified, semester-long web portal designed for college students, faculty, and administrators. It consolidates academic information, schedule tracking, attendance monitoring, examination records, fees management, campus events, and administrative workflows into a single responsive web platform.

### 2. User Roles & Modules
1. **Public / Guest:**
   - Homepage with campus highlights and announcements
   - About University & Department
   - Faculty Directory & Consultation hours
   - College Events & Competitions catalog
   - Student Registration & Inquiries
2. **Student:**
   - Secure Authentication & Session Dashboard
   - Subject-wise Attendance Tracking
   - Weekly Academic Schedule / Timetable
   - Semester Examination Results & CGPA view
   - Fee payment history and breakdown
   - Event participation registration
3. **Administrator:**
   - Administrative Dashboard with system metrics
   - Student Account Management (CRUD, Search, Filter, CSV Export)
   - Event Management (CRUD with poster image upload)
   - Asynchronous AJAX Management via RESTful JSON API
   - Audit Logging for security and accountability
